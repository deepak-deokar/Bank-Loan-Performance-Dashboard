# Bank Loan Performance Dashboard

This project features an interactive dashboard built in Excel to analyze and visualize bank loan performance. It's designed to provide insights into key loan metrics, track trends, and help in data-driven decision-making.

## Key Features

- **Interactive Dashboard:** A user-friendly and dynamic dashboard created entirely in Excel.
- **Data Visualization:** Includes various charts, graphs, and tables to represent the loan data effectively.
- **Key Performance Indicators (KPIs):** Tracks important metrics such as total loan applications, default rates, and average loan amount.
- **Data-Driven Insights:** Helps in identifying trends and patterns in loan data.

## Files in this Repository

- `Bank Loan Data.xlsx`: The raw dataset used for the analysis.
- `Bank_Loan_Performance_Dashboard.xlsx`: The main Excel file containing the interactive dashboard and visualizations.
- `images/`: A directory containing screenshots of the dashboard.
  - `Overview Dashboard.png`
  - `Summary Dashboard.png`

## Getting Started

To get started with this project, you will need to have Microsoft Excel installed on your computer.

1. **Download the files:** Clone or download this repository to your local machine.
2. **Open the Dashboard:** Open the `Bank_Loan_Performance_Dashboard.xlsx` file in Excel.
3. **Explore the Dashboard:** Interact with the dashboard to explore the loan performance data. The dashboard is designed to be intuitive, but you may need to enable macros or data connections if prompted by Excel.
